One exported function per file, named exactly after the function: `guessGender` → `src/guessGender.ts`, `normalizeName` → `src/normalizeName.ts`. Types and interfaces the function takes or returns may live beside it.

- Private helpers may stay unexported in the same file. When a second file needs one, give it its own file.
- No barrel files, with one exception: `src/index.ts` is the package's public entry point and only re-exports. Internal code imports from the function's own path, never from `src/index.ts`.
- Group by domain in a folder (`src/data/`), still one function per file.
- Files under `src/data/` are generated by `scripts/build-data.ts`. Change the script, never the output.
